Your browser AI,

Turn the Gemini, ChatGPT, Claude or DeepSeek you're already logged into into an OpenAI-compatible endpoint — with streaming, tools that actually edit files, and multi-account failover. No API keys. No per-token billing.

Get started Roadmap
# start the bridge with your logged-in Gemini
$ bab serve --site gemini
# use it from any OpenAI-compatible client
$ curl http://localhost:3000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model":"gemini","messages":[{"role":"user","content":"Fix the bug in src/app.ts"}]}'

Why Browser AI Bridge

The assistant you already pay for, wired into the tools you already use.

🎯

Real tokens, not scraping

CDP interception captures the provider's actual SSE stream, with a DOM fallback for resilience.

🛠️

Tools that do the work

Read, edit, search, git and shell — with a permission engine that asks before anything dangerous.

🔄

Multi-account rotation

Several logged-in profiles per provider, auto-switching on rate limits and CAPTCHAs.

👥

Team mode

One server, many IDE clients — RBAC roles and per-client session isolation.

⚡

Native API fallback

Bring an OpenAI / Anthropic / Google key and it streams directly when the browser isn't available.

🔒

Private by default

Runs locally. No credentials are stored, and responses are redacted before logging.

Three steps

From zero to an AI pair-programmer in your editor.

Connect

Run bab serve --site gemini and it opens your logged-in session.

Point your IDE

Add http://localhost:3000/v1 as a custom OpenAI endpoint in Cursor, VS Code or Continue.

Ship

The AI reads files, edits them and runs your build — with your approval.
